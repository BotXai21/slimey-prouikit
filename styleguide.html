Overview

ProUIKit 2.0 combines component-driven patterns with a utility-first system, responsive variants, design tokens, and a modern component library. This demo showcases components and utilities that resemble Bootstrap's completeness and Tailwind's utility approach.

Tokens

Colors, spacing, radii, shadows, motion and breakpoints are exposed as CSS variables for theming and runtime overrides.

Utilities

Use utility classes for spacing, sizing, text, layout, and interactivity — includes responsive prefixes and state variants.

Components

Buttons, forms, navs, modals, drawers, tooltips, charts placeholders, datagrids and dashboard widgets.
